# Walmart Sales Analysis
An end-to-end retail sales analytics project using Python, SQL, and Power BI.
## Project Overview
This project analyzes Walmart retail sales data to identify sales trends,
store performance, department performance, holiday patterns, and business insights.

The project covers the complete analytics workflow:
- Data cleaning using Python
- Data analysis using Python
- SQL-based business queries
- Interactive Power BI dashboard
- Business insights and visualization
